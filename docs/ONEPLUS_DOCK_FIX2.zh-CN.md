# OnePlus 底部悬浮输入条 · fix2

目标设备信息由用户提供：OnePlus 13s，骁龙 8 至尊版、16 GB 内存、OxygenOS 15.0 / Android 15。此版本在 `oneplus-adaptation` 分支开发，继续使用 fix1 的汉化签名。

## 界面变化

- 默认“现代”样式改为底部圆角输入条，初始不再绘制标题和空白消息区域。桌面区域透明，不绘制全屏暗色蒙层；触摸范围跟随浮层实际边界，避让系统手势区。
- 输入条保留“＋”、编辑框、麦克风和语音对话按钮。输入文字或添加附件后，右侧成为发送；回复生成时成为停止；语音对话开启时可再次点击结束。
- “＋”菜单提供添加附件、模型切换、历史、新建聊天、屏幕和关闭。附件与屏幕菜单沿用原有相机、图库、文件、剪贴板、完整屏幕和选择区域流程。展开后仍可使用标题栏中的模型、历史、新建和关闭。
- 可用时在输入条上方显示“使用屏幕”小胶囊；点击附加/取消屏幕，长按打开屏幕/区域选项。屏幕授权与应用隐私策略继续由原有流程决定。
- 发送问题、开始生成回复时向上展开；短回复按内容取高，长回复在安全区域内滚动。下滑把手、标题区域，或在消息顶部下滑可收起；点击/上滑把手再展开。收起保留草稿、聊天和正在运行的请求。
- 返回键依次关闭菜单、隐藏键盘、收起内容，再关闭浮层。默认唤起不自动抢走输入焦点；手动点击编辑框后使用既有键盘连接流程。
- 默认表面跟随系统浅色/深色，自定义主题表面及 AMOLED 设置优先。键盘动画期间按 IME inset 移动浮层，底部使用键盘与系统栏 inset 的较大值，横屏同时避让侧边系统栏和刘海。窗口较宽时输入条宽度限制为 520 dp。
- 内容高度通过 240 ms 动画变化，输入条保持底部锚定；尊重系统关闭动画的设置。零高度收起时显式裁剪并隐藏内容，避免标题在桌面上漏画。

经典、Float 和专属样式继续保留。原有设置预览的现代样式也已更新为新的输入条结构。

## 覆盖安装 fix1

1. 直接安装 `Orbit-Assistant-v0.8.4.1-zh-CN-OnePlus-Dock-fix2.apk`，选择更新。不要先卸载 fix1。
2. 如果此前手动选择过其他悬浮样式，在设置 → 外观中选择“现代”，即可使用本次底部输入条；默认样式即为现代。
3. 本次主程序与配套本地 AI 组件的安装版本号均为 **819**（fix1 为 818）。进入本地 AI 页面若提示组件需要更新，点击“更新组件”，按 Android 提示完成覆盖更新。组件已内置于 APK。
4. 主程序和组件均继续使用 fix1 的同一证书。覆盖更新保留主程序数据和组件中的模型，无需卸载组件或重新下载已完整安装的模型。若系统提示签名冲突，请核对是否安装的是本次文件以及原版本是否确为本汉化 fix1，不要通过卸载来处理。
