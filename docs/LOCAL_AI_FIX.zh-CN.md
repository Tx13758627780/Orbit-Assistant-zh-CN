# 本地 AI 修复说明（zh-CN localai-fix1）

基于上次交付的 v0.8.4.1 简体中文源码；上游基线为 `32655b8cd9dc6149b4264b476c8db0d6aab9cff2`。

## 已查明的问题

上次交付的主程序是调试签名 APK，证书 SHA-256 为
`103D1A208F0A62FD18C90E82D366FA74BFCAD7C4DB8057291FF4A80012A41026`。
本地组件的官方证书则为
`7DAD619385DFF11EC731AA555F2B448A943C7391813D1A94DF1CB4232ECD41E3`。
主程序仍从上游下载官方组件，并只按官方证书检查组件。组件因此会被主程序识别为“已安装”，但 Android 的 signature 权限不允许调试签名主程序绑定官方组件；组件也会在每次 IPC 调用时核查主程序证书。这一组合无法工作。

页面将“尚未取得状态”和“连接已失败”都表示为 `status == null`，两者均显示“正在检查”，并隐藏模型下载按钮。因此即使绑定已经失败，也会一直显示检查中；未返回的状态读取还可能使轮询一直保持进行中。

已逐文件比对原汉化交付源码与上游：`OrbitLocalComponent`、`OrbitLocalClient`、`OrbitLocalStatus`、`OrbitLocalStatusPoller`、`OrbitLocalInstaller`、`LocalModelStore` 及全部本地组件 Java 源码均未被汉化修改。状态枚举、Bundle key、AIDL、包名、权限名、模型 ID/文件名、URL 和模型 SHA-256 未被翻译。根因是交付时没有处理重新签名后的配套组件，而不是这些英文常量被翻译。

## 本次修改

1. 主程序和本地组件使用本汉化版本自己的同一套正式构建签名。双方固定核验该证书，保留 Android 的 signature 权限、单一签名者检查、包名、精确版本及 IPC 协议检查。构建时还检查证书 pin 是否与实际签名密钥一致；没有接受任意签名或关闭校验。
2. 主 APK 内置同批构建的组件安装包及其 SHA-256 元数据。“安装组件”从内置包准备安装，仍完整验证后交给 Android 确认，不再混用官方组件。组件安装仍需用户确认，模型不随 APK 捆绑。
3. 两个模型卡片区分首次检查与连接失败。检查失败显示原因和“重试连接”。单次读取 12 秒超时，轮询继续；离开页面、超时或重试后到达的旧回调不能覆盖新状态。
4. 状态客户端最多保留一个后台读取，防止 Binder 阻塞时重试任务无限排队。

普通上游构建不设置本汉化构建参数时仍使用上游证书 pin 和原来的分发方式。捆绑模式要求 Release 构建，防止再生成签名不匹配的 Debug 主程序与 Release 组件组合。

## 安装

1. 先使用旧版提供的导出功能备份重要会话和数据。旧调试签名密钥已无法取回，新版不能覆盖安装旧汉化版。卸载会删除应用私有数据；卸载组件也会删除组件内的模型。不要在没有备份时直接卸载。
2. 在 Android 设置中卸载旧的 Orbit 助手，以及旧的 Orbit Local / Orbit 本地 AI 组件。
3. 安装本次交付的 `Orbit-Assistant-v0.8.4.1-zh-CN-localai-fix1.apk`。
4. 进入设置 → AI 与账户 → AI 提供方 → Orbit 本地 AI，点击设置/安装组件，按 Android 提示允许来自本应用的安装并确认。配套组件已内置，不需要另找官方 APK。
5. 组件就绪后，分别点击聊天模型和操作模型的“下载模型”。聊天模型为 1,598,556,720 字节，操作模型为 546,660,344 字节；约 35 MB 的组件本身不包含模型。请留出下载和校验所需空间，并确保能连接模型下载站点 Hugging Face。
6. 模型下载完成后选择 Orbit 本地 AI；如需要本地设备操作，再开启对应开关。模型完整安装后可离线使用。

不要混装官方签名组件。汉化版使用独立签名，官方在线更新也不能覆盖它，请后续使用同一汉化签名发布的更新。本次私有签名备份单独交付，不能上传到公开 GitHub 仓库。

## 源码构建

使用 JDK 17、Android SDK 36、Build Tools 35.0.0 和仓库 Gradle Wrapper。按已有说明在被忽略的 `orbit-signing.properties` 中配置 `ORBIT_RELEASE_*` 四项，并使用单独交付的私有签名备份恢复签名身份。

```sh
./gradlew -PorbitBundledLocal=true \
  -PorbitLocalizedCertificateSha256=<签名证书SHA256，64位十六进制> \
  :app:assembleRelease
```

这会先构建并签名组件，再将它和生成的校验元数据加入主 APK。私钥、密码和本机配置不在公开源码包中。修复补丁以旧汉化源码为基线，完整源码包已包含补丁；不要重复应用。
